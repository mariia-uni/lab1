# Лабораторна робота №1: Об'єктно-орієнтоване моделювання математичних функцій, фігур та графів

Цей проєкт є реалізацією об'єктно-орієнтованої програми на Python для моделювання математичних функцій (символьних та табульованих), геометричних фігур на площині, обмежених цими функціями, а також аналізу їх взаємозв'язків за допомогою структур даних графів.

---

## Виконання вимог завдання

Згідно з умовами лабораторної роботи, проєкт повністю задовольняє наступні кількісні та якісні критерії:

### 1. Кількісні показники реалізації
* **Не менше 9 класів:** У проєкті реалізовано рівно **9 класів** (`FunctionProvider`, `SymbolicFunctionProvider`, `TabularFunctionProvider`, `Shape`, `SingleFunctionShape`, `DoubleFunctionShape`, `CompositeShape`, `ShapeGraphNode`, `ShapeGraph`).
* **Не менше 15 полів:** У всіх класах у сумі реалізовано **21 поле** (наприклад, `expr_str`, `x_data`, `y_data`, `name`, `color`, `func_provider`, `lower_func`, `upper_func`, `nodes_map`, `sub_shapes` тощо).
* **Не менше 25 нетривіальних методів або функцій:** Реалізовано понад **25 методів**, які виконують аналітичне та чисельне інтегрування, лінійну інтерполяцію, побудову графів, пошук шляхів (BFS) та перевірку зв'язності.

### 2. Предметна область та функціонал (Варіант `****`)
* **Фігури, задані однією або двома функціями:** 
  * Клас `SingleFunctionShape` моделює фігуру від осі X до графіку невід'ємної функції.
  * Клас `DoubleFunctionShape` моделює фігуру між двома графіками функцій (обмежену зверху та знизу).
* **Обчислення площі та периметра:** Реалізовано точні символьні розрахунки через інтегрування за допомогою бібліотеки **SymPy**, а також чисельні методи (метод трапецій, апроксимація довжини дуги) для табульованих даних.
* **Фігура-перетин (Intersection):** Метод `intersect()` для кожної фігури дозволяє обчислити та створити нову складну фігуру перетину.
* **Фігура-об'єднання (Union):** Клас `CompositeShape` підтримує операцію об'єднання кількох геометричних фігур.

## Архітектура програмного забезпечення

### 1. Провайдери функцій (`FunctionProvider`)
* **`SymbolicFunctionProvider`**: Парсить рядкові математичні вирази через `SymPy`, виконує аналітичне диференціювання та підстановку значень.
* **`TabularFunctionProvider`**: Працює з дискретними наборами точок, забезпечуючи обчислення значень за допомогою лінійної інтерполяції.

### 2. Геометричні фігури (`Shape`)
* Абстрактний базовий клас `Shape` задає загальний інтерфейс для розрахунку площі (`calculate_area`), периметра (`calculate_perimeter`) та перетину (`intersect`).
* Композитні структури (`CompositeShape`) дозволяють об'єднувати фігури в складніші логічні одиниці (об'єднання/перетин).

### 3. Графова структура (`ShapeGraph`)
* Дозволяє зв'язувати фігури між собою в орієнтовані або неорієнтовані графи.
* Містить вбудовані алгоритми обходу в ширину (**BFS**) для перевірки зв'язності графа (`check_connectivity`) та пошуку найкоротшого шляху між фігурами (`find_path`).
